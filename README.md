## Project Overview
This website was created for Cape Town Football Academy, a grassroots football academy in Cape Town that helps young players develop their skills, confidence, discipline and teamwork.

## Website Goals and Objectives
- Provide clear information about the academy and its services
- Allow parents and players to enquire about joining
- Make it easy to contact the academy
- Create a professional and mobile-friendly website

## Key Features
- 5 pages with consistent navigation
- Enquiry form and Contact form with JavaScript validation
- Interactive accordion on the Services page
- Responsive design using Flexbox and media queries
- Basic SEO (titles, meta descriptions, robots.txt, sitemap.xml)
